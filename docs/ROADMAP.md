# Esprit Architecture & Roadmap

Esprit is an autonomous AI operating layer for local codebases.

## Implemented Features
- [x] Petgraph AST Memory Graph
- [x] Background System Daemon
- [x] SQLite Branching Chat
- [x] Ratatui Dashboard
- [x] Streaming LLM Rendering
- [x] WASM Plugin Sandbox
- [x] Codebase Vector Space Mapping (Semantic Grep)
- [x] Long-Term Memory Compression
- [x] Real-Time AST Diffing & Tracing
- [x] Documentation-to-Code Drift Detection
