# Contributing to Esprit

Thank you for your interest in contributing!

## Development Workflow
1. Fork the repository and create your feature branch.
2. Ensure you have the required Rust toolchain installed.
3. Run `cargo fmt --all` to match project style guidelines.
4. Run `cargo clippy --workspace` to catch common mistakes.
5. Ensure tests pass via `cargo test --workspace`.
6. Submit a Pull Request!
