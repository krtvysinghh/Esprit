# Linux Installation

## Debian / Ubuntu

sudo dpkg -i esprit_0.1.0_amd64.deb

## Fedora / RHEL

sudo dnf install ./esprit-0.1.0-1.x86_64.rpm

## Arch Linux

makepkg -si

## Snap

sudo snap install esprit

## Flatpak

flatpak install org.krtvysingh.Esprit

## AppImage

chmod +x Esprit.AppImage
./Esprit.AppImage
