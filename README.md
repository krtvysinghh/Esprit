## 📖 Overview

**Esprit** is a local-first intelligence engine for working with files, projects, codebases, knowledge, and AI-powered workflows.

Built around a modular Rust workspace, Esprit provides the foundation for:

- 🧠 Local AI and model integration
- 📂 Filesystem intelligence
- 🔎 Full-text and semantic search
- 🧬 RAG and embeddings
- 🧠 Persistent local memory
- 🤖 AI agents
- ⚙️ Workflow orchestration
- 🔌 Plugin systems
- 📊 Code intelligence
- 💾 Local storage and caching
- 🛡️ Security-focused tooling
- 🖥️ Cross-platform applications

> **Your data should remain close to your intelligence.**
